# пинг таблет 2017 - ∞

Интерактивная фотокнига с редактором и музыкальным сопровождением. React 19, Vite, StPageFlip, IndexedDB.

## Запуск

```sh
npm install
npm run dev
```

Для публикации: `npm run build`. Содержимое `dist/` можно разместить на статическом хостинге. Локальный просмотр production-сборки: `npm run preview`.

## Возможности

- Перелистывание за углы, перетаскиванием, свайпом, кнопками и стрелками клавиатуры. Твёрдая обложка, изгиб листа, тени, толщина и наклон книги.
- Режимы просмотра и редактирования. Создание и удаление страниц, изменение порядка перетаскиванием миниатюр. Удалённую страницу можно вернуть кнопкой в уведомлении.
- Множественная загрузка и drop фотографий. Изображения сохраняются в исходном разрешении. JPG/PNG/WEBP; HEIC/HEIF — только если браузер умеет их декодировать.
- Перемещение фото по странице в редакторе. Ширина, высота, кадрирование, выбор точки кадра, подписи, текст, фон и макеты. Настройка названия и обложки.
- Просмотр исходников: масштаб 100–800%, колесо, pinch, pan, двойное нажатие, сброс и полноэкранный режим (если доступен браузеру).
- Плейлист с загрузкой аудио, чтением ID3/MP4-метаданных и обложек. Play/pause, seek, громкость, repeat, shuffle. Переименование, удаление, изменение порядка мышью и кнопками в меню трека. Звук не прерывается сменой страниц и режима. Старт звука — только по действию пользователя.
- Автосохранение в IndexedDB. Экспорт и импорт `.memoria`, включая пользовательские фото и аудио. При импорте открытая книга заменяется.
- На узких экранах — одна страница и выдвижная панель музыки. Поддержка клавиатуры, focus states, reduced motion.
- Все 44 иллюстрации из `public/archive/` автоматически появляются на внутренних страницах: по три полностью непрозрачных декоративных изображения на страницу. Пользовательские фотографии остаются полноразмерными.

## Хранение и ограничения

Приложение работает без сервера и аккаунта. Библиотека хранится в браузере на текущем устройстве. Очистка данных сайта удаляет локальную книгу. Для резервной копии используйте «Сохранить книгу». Большие исходники и аудио ограничены доступной памятью браузера; ошибки записи показываются в интерфейсе. Файлы сохраняются как data URL без уменьшения разрешения; это увеличивает размер резервной копии примерно на треть. Браузер определяет доступные аудиокодеки и поддержку Fullscreen API.

Демонстрационная книга содержит фотографии Unsplash (локальные файлы), саундтрек — оригинальная синтезированная ambient-композиция. Интерфейс использует Manrope и Cormorant Garamond через Google Fonts с системными fallback-шрифтами.

## Движок страниц

`src/vendor/page-flip.js` — StPageFlip 2.0.7 (MIT), с исправлением жизненного цикла: остановка requestAnimationFrame и снятие resize-обработчика при уничтожении. Это предотвращает накопление фоновых циклов во время редактирования. Лицензия рядом. Изгиб страницы рассчитывается геометрически движком StPageFlip; отдельная физическая симуляция бумаги и WebGL-сетка не используются.

## Проверка

`npm run build` — production-сборка. В браузере проверены desktop 1440×1000 и mobile 390×844: переход по разворотам, просмотр фото и масштаб, переключение режимов, выбор и загрузка фотографий, загрузка WAV, плеер при перелистывании, мобильная панель. Жесты на физическом телефоне не проверялись.

## Массовая загрузка

Нажмите «Добавить фото», выберите размещение по 1, 2 или 4 фотографии на новой странице и затем выделите все нужные файлы. На компьютере можно использовать Cmd/Ctrl+A или Shift. Существующие страницы сохраняются; новые вставляются после выбранной. При добавлении на текущую страницу размещается до 4 снимков, остальные распределяются по новым страницам по 4. Drop большой партии на книгу по умолчанию создаёт отдельную страницу для каждого фото.

В музыкальной панели нажмите «Добавить треки» и выделите несколько файлов. Можно также перетащить всю партию в панель. Порядок файлов сохраняется; треки добавляются одним обновлением после обработки. Прогресс виден и у фото, и у музыки. Одновременно читаются до трёх файлов, ошибка одного файла не останавливает остальные.

Проверено дополнительно: browser upload 12 JPG + один повреждённый JPG (12 добавлены на 3 страницы), 8 WAV одной партией. Модульные проверки `node --test tests/batch.test.js`: порядок и частичный сбой партии, ограничение параллельных операций, распределение 103 фото с сохранением существующих страниц.

## Подарочная публикация (только просмотр)

Подарочная версия собирается отдельно с `VITE_VIEW_ONLY=true`. В ней нет редактора, импорта, экспорта, удаления, очистки, переименования и загрузки файлов. Остаются перелистывание, просмотр и увеличение фотографий, полноэкранный режим и воспроизведение готового плейлиста.

В подарочном режиме скрыты пояснительные панели, нижняя лента миниатюр и обзор страниц: остаются сама книга и саундтрек. Перелистывание доступно за верхний и нижний угол страницы.

1. В обычной версии откройте настройки книги → **Подготовить книгу в подарок**. Скачается файл `book.json`.
2. Положите `book.json` в `public/book.json` проекта. Он содержит выбранные страницы, фотографии как data URL и музыку как data URL, поэтому исходные файлы отдельно для публикации не нужны.
3. Запустите `npm run build:gift` и проверьте `npm run start`.
4. Для Railway используйте этот репозиторий: build command `npm run build:gift`, start command `npm start`. Файл `railway.json` уже содержит эти значения и healthcheck `/`.

Редактирование и публикация разделены: свои изменения делайте в редакторе на `http://localhost:5173/`. После очередных изменений снова нажмите **Подготовить книгу в подарок**, замените скачанный `book.json` в папке `public/` репозитория и отправьте его в GitHub. Railway автоматически пересоберёт view-only сайт.

Если push из терминала ещё не настроен, в локальной копии репозитория выполните один раз `git config user.name "Ваше имя"`, `git config user.email "ваш-email"`, затем `git add public/book.json && git commit -m "Update gift book" && git push`.

`VITE_VIEW_ONLY` вшивается на этапе сборки. Удаление `?gift=1` из адреса не включает редактор: на Railway будет опубликована отдельная view-only сборка.
